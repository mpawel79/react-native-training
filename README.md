# React Native Training

This repository contains my progress through the React Native training course from [React Native Tutorial for Beginners - Build a React Native App [2023]](https://www.youtube.com/watch?v=S6RAbmXGyLo).

## Repository Structure

Each branch in this repository represents a different lesson or milestone from the course. The branches contain working examples and implementations of the concepts covered in the tutorial.

## Course Content

The course covers fundamental React Native concepts including:
- Navigation setup and configuration
- Screen creation and management
- Drawer navigation implementation
- Component styling and layout
- And more...

## Getting Started

To explore different lessons:
1. Clone the repository
2. Check out different branches to see various implementations
3. Each branch contains a working example of the concepts covered in that lesson
